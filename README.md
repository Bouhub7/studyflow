# StudyFlow

A lightweight study planner built with vanilla HTML, CSS and JavaScript. StudyFlow helps students organize coursework, track task completion and plan focused study sessions.

## Features

- Add tasks with a subject and priority
- Mark tasks as completed and filter the task list
- Track remaining tasks and completion progress
- Plan study sessions with a chosen duration
- Save tasks and sessions locally in the browser using `localStorage`
- Responsive layout for desktop and mobile
- No framework, build step or external API required

## Run locally

1. Clone or download this repository.
2. Open `index.html` in your browser.

That's it — no installation required.

## Privacy

StudyFlow stores its data in the browser's local storage. It does not send task or session information to a server.
